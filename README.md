# Privacy Policy for Pickr for Netflix

최종 수정일: 2026년 10월 17일

'Pickr for Netflix' (이하 "확장 프로그램")는 이용자의 개인정보를 매우 소중하게 생각하며, 어떠한 개인정보도 무단으로 수집하거나 이용하지 않습니다.

### 1. 개인정보의 수집 및 이용
본 확장 프로그램은 이용자의 개인 식별 정보(이름, 이메일, 계정 정보 등)나 넷플릭스 시청 기록, 검색 기록을 일절 수집, 저장, 전송하지 않습니다.

### 2. 권한 사용 목적
- storage: 이용자가 설정한 테마(다크/라이트), 블러 기준 평점, 미평가 블러 여부 및 24시간 동안의 평점 캐시 데이터를 브라우저 로컬 환경에 저장하기 위해 사용됩니다.
- host_permissions (*://*.netflix.com/*): 넷플릭스 웹페이지의 작품 제목을 읽어 평점 배지를 오버레이 렌더링하기 위해 사용됩니다.
- host_permissions (https://api.themoviedb.org/*): TMDB 공식 오픈 API로부터 작품의 공개 평점 정보를 실시간으로 조회하기 위해 사용됩니다.

### 3. 제3자 제공 및 외부 전송
본 확장 프로그램은 어떠한 사용자 데이터도 개발자 서버나 제3자에게 전송하거나 판매하지 않습니다.

### 4. 문의처
